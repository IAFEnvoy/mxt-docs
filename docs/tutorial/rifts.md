# 裂隙

## 你要搭建什么

一扇贴合门框的平面门，通向当前维度的精确落点；再把它导出成秘境布局。设计需要 2 级 OP，通行不要求 OP。

## 第 1 步 —— 记录落点

```mcfunction
give @s mxt:rift_anchor
```

站到安全落点，潜行使用锚。它记录维度、坐标与朝向。脚下要有支撑，身体空间不能有碰撞或液体。

## 第 2 步 —— 打开草稿

走到门框，拿锚右键门框的一个方块面。编辑器以命中面为平面，不替换任何方块。切换目标页，核对记录的坐标；切换放置页，把 enabled 设为 true。也可执行 `/mxt rift edit` 创建禁用草稿。

## 第 3 步 —— 调整轮廓

先生成矩形或拱门，再拖顶点贴合建筑。吸附间距 `0.0625` 对应 1/16 格。Shift 多选、框选与数值坐标可同时调整多个点；滚轮缩放，右键拖动画布。边工具同时移动两个端点。

世界预览用于检查贴合效果。需要倾斜门时，先选三点平面工具，再进入预览并开启世界编辑。在顶部面板外按住右键拖动视角，用屏幕中心瞄准，左键点击三个不共线的方块命中点。Esc 退出世界编辑，面板按钮始终可用。无效草稿显示红色，不能发布；撤销会保留先前形状。

## 第 4 步 —— 应用与导出

点击应用后，整扇门一起发布。默认持续时间 `0` 为永久，普通编辑不会续期。

蓝图页可保存到主手锚，或导出预设、布局、相对位置布局、本地目的地布局。导出先复制 JSON；保存文件需要另点按钮。预设放到 `data/<namespace>/mxt/rift/<path>.json`；布局的 `portals` 数组并入秘境定义，不能把这个片段当作完整秘境定义。

## 在游戏里验证

```mcfunction
/mxt rift info
/mxt rift spawn mxt:rectangle ~ ~ ~ south position minecraft:overworld ~8 ~ ~
```

1. `info` 给出门 UUID，用它执行 `edit`、`enabled`、`duration`、`remove`。
2. 走进实际门面才传送；凹口与门框不传送。目标不安全会保留原位置。
3. 应用后重新打开编辑器，应看到同一轮廓和目的地。
4. 普通玩家的秘境令牌右键召门，接触才进入；秘境内的令牌召返回门。

## 常见错误

| 现象 | 原因 |
| --- | --- |
| 门不传送 | 门被禁用、在冷却中、没有碰到轮廓，或落点不安全。 |
| 形状无法提交 | 自交、连续共线、重复点、点数/尺寸超限或越过世界边界。 |
| 不能编辑 | 缺少 2 级 OP，距离超过 64 格，或编辑会话已失效。 |
| 保存文件失败 | 尚未导出、名称无效或同名文件已经存在。 |
| 出口没有包含在建筑 NBT 中 | 门是独立世界记录，需要另外导出 portals 布局。 |
