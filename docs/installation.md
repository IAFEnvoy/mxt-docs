# 基本信息与安装

MiXianTu 是 NeoForge 模组，安装方式与其他模组相同：先准备与所需 Minecraft 版本匹配的 NeoForge 安装，再把 MiXianTu 本体 Jar 及其必需前置放进客户端与服务端的 `mods` 文件夹。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.99` 或更高 |
| 运行侧 | 客户端与服务端（`BOTH`） |
| Mod ID | `mxt` |
| 许可证 | `All Rights Reserved` |

## 必需前置

Jupiter 是必需前置，且**没有**打进模组 Jar，需要与 MiXianTu 一起单独安装；其余必需前置都通过 Jar-in-Jar 打包在 MiXianTu 内部，无需手动下载。

| 前置 | 状态 |
| --- | --- |
| Jupiter | 必需，需单独安装 |
| Curios API `15.0.0+26.1.2` | 必需，随模组打包 |
| 其他必需库 | 随模组打包 |

## 可选兼容

下列模组都是可选兼容，不装也能正常游玩。

| 模组 | 作用 |
| --- | --- |
| KubeJS `26.1.2-8.0.4` | 仅在你想用脚本注册内容时需要，见 [KubeJS](./kubejs/index.md) |
| JEI | 配方查看集成：显示灵气有序合成与灵气无序合成及其灵气消耗 |
| Jade | 方块信息集成：方块灵气、灵气工作台的灵气与展示架中储存的灵力 |

::: info KubeJS 不是硬前置

只有从脚本注册的内容才需要 KubeJS；纯数据包方案不需要它。

:::

## 配置

所有配置都在**游戏内的配置界面**里修改：打开**模组列表 → 觅仙途 → 配置**，界面顶部可以在「客户端设置」与「觅仙途服务端配置」之间切换。不需要、也不建议手改 `config/` 下的文件。

| 部分 | 权限 | 包含的标签页 |
| --- | --- | --- |
| 客户端设置 | 无（只影响本机） | 技能快捷栏、资源条、人物信息面板、功法、裂隙 |
| 觅仙途服务端配置 | **OP** | 饰品栏、修炼、符箓、灵气、阵法、命令别名、兼容 |

服务端配置改完会同步给已连接的客户端。本文档提到配置时一律写作**服务端配置「标签页 → 条目」**或**客户端配置「标签页 → 条目」**，按这个名字在界面的对应标签页里找即可。

## 玩法从哪里来

MiXianTu 提供通用的规则与运行时——修炼、灵气环境、境界与数值、技能、阵法、天劫、锻造、炼丹与经济——但不预设任何具体世界观数值。具体物品、方块和配方由数据包、KubeJS 或其他内容模组提供，MiXianTu 的数据表与绑定表再赋予它们玩法。

只装本体时得到的是框架物品、Curios 槽位、HUD 和命令；本体不含境界数值、技能或配方，因此在加入内容之前游戏里不会有变化。

- 想用数据包写这些内容，从[数据包开发总览](./datapack/overview.md)开始，再到 [JSON 数据格式](./datapack/json/index.md)查具体字段。
- 想在这个框架上做内容包并分发，许可方面的说明见[常见问题](./faq.md)。

## 开发运行

```bash
gradlew runClient
gradlew runTestClient
gradlew runTestServer
```

`runTestClient` 会额外加载 `src/test-mod`，用于手动验证数据包与客户端显示；测试模组不会打进正式 Jar。
