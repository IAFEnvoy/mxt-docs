# MiXianTu

MiXianTu（觅仙途，模组 ID `mxt`）是一个 NeoForge **修仙模组框架**。它提供修仙玩法所需的**通用规则与运行时**——修炼、灵气环境、境界与数值、技能、阵法、天劫、锻造、炼丹与经济——但不预设任何具体世界观数值。

具体物品、方块和配方由数据包、KubeJS 或其他内容模组提供，MiXianTu 的数据表与绑定表再赋予它们玩法。

- **玩家**：只装本体时得到的是框架物品、Curios 槽位、HUD 和命令；实际能玩到什么取决于你使用的数据包或内容包。
- **内容与模组作者**：用数据包、KubeJS 或 Java API 定义自己的修炼规则、灵气分布、技能、阵法、工艺和物品绑定，不需要改动模组本体。

::: warning 项目仍在开发中

项目尚未发布，数据包格式与其他接口都还不是最终形态，更新后可能不再兼容旧存档或旧数据包。会造成崩溃或数据丢失的改动会在更新日志里单独说明。

:::

## 模块完成度

- **✅ 完成**：已经实现，装上即可使用；后续仍可能有小幅调整。
- **🚧 制作中**：只完成了功能集的一部分，其余仍在开发。
- **🔲 预留**：只有数据结构或资源，或仅有开发计划。

| 模块 | 状态 | 说明 |
| --- | :---: | --- |
| 数据包内核 | ✅ | 玩法规则由数据包描述：条件、行为、数值计算、物品匹配与触发时机都能自由组合，单条定义可以随时禁用。 |
| 快捷栏与人物界面 | ✅ | 玩家可以用按键打开技能与灵力快捷栏并直接施放，打开人物信息面板查看自身状态，并选择哪些条目显示在快捷栏上。 |
| 数值 | ✅ | 可以定义修为、灵力等数值；它们按规则回复，被技能和修炼消耗，并以资源条绘制在 HUD 上。 |
| 灵气 | ✅ | 世界中每个维度、生物群系和方块都有不同浓度的灵气，并随时间与阵法变化；玩家可以查询所在位置的浓度，并通过粒子、雾效和 HUD 看到结果。 |
| 修炼与境界 | ✅ | 玩家可以打坐积累修为，灵气越浓越快；满足条件后可以突破到下一境界，条件由数据包定义。 |
| 元素 | 🚧 | 定义元素以及元素之间的克制与适应关系，供灵根、灵气和其他玩法读取。 |
| 灵根与体质 | 🚧 | 灵根和体质可以授予玩家，影响修炼与技能强度，或直接提供被动属性；如何获得、哪些互斥由数据包定义。 |
| 功法 | 🚧 | 玩家可以学习功法以获得主动招式或被动加成，互斥标签可以阻止某些功法同时修习；功法可以绑定到任意现有物品作为载体。 |
| 技能与诅咒 | 🚧 | 技能可以从快捷栏施放，带有消耗、冷却、持续时间和目标选择，也可以在攻击、受击、击杀等时机自动触发；诅咒附着在角色身上，周期触发并可被净化解除。 |
| 阵法 | ✅ | 玩家可以搭建并激活阵法；阵法持续消耗资源维持，在范围内施加效果，并临时提供增益或减益。 |
| 天劫 | 🔲 | 境界突破时可能触发天劫：它消耗一条时间线，随环境变得更难，成功与失败各有自己的结果。 |
| 生物档案与契约 | 🔲 | 生物档案定义生物的实力、内丹与掉落；玩家也可以与生物签订契约，让灵兽跟随战斗、收进御兽铃或召回。 |
| 秘境 | ✅ | 秘境定义是一份模板：每次进入都会按它开出一份独立的实例维度，可以设置边界、结构与落点，并限制实例数量、在场人数与时限；秘境可以被第一个进入者认领，认领后没人时维度卸载但保留地形，下次进来接着用。 |
| 灵性合成台 | ✅ | 在灵性合成台合成除材料外还需消耗灵气，取出结果时扣除。 |
| 锻造 | ✅ | 在锻造台上按图纸把若干材料锤打成成品；不同工具解锁不同手法，成品品质取决于过程与步骤数。 |
| 炼丹 | 🚧 | 配方把材料、灵气、温度和丹炉等级组合成丹药，成功与失败的结果都由配方决定；服丹生效，服得太多会累积丹毒。 |
| 灵植 | 🔲 | 定义灵植物品的绑定与品质，作为炼丹与采集玩法的材料。 |
| 物品绑定 | 🚧 | 把现有物品接入玩法：给任意物品附加被动行为、武器伤害与攻击速度，或绑定右键使用与攻击时触发的技能。 |
| 符箓 | 🚧 | 符笔把技能定义铭刻到载体上（一个载体可以铭刻多张），容量即这些定义计费的灵气；按住右键灌满会发动所有已铭刻的技能并消耗一个载体。摆在展示架上被填满时同理——架子上的载体不在任何人手里，因此**谁把它填满就由谁发动、永远消耗一个载体、也不进使用冷却**；而右键发动一次消耗一个载体（创造模式不消耗），并开始物品冷却。 |
| 物品品质 | 🚧 | 物品可以携带品质并显示在 Tooltip 中，可以按品质分组和排序，品质组也能被其他玩法作为条件读取。 |
| 法器 | 🚧 | 法器可以储存灵力、载人飞行或提供技能，并附带一套炼器玩法。 |
| 经济 | ✅ | 物品可以被定义为货币并带有面值，支持兑换与找零；玩家之间可以直接交易，也可以使用交易站和票据结算。 |
| Curios 槽位 | ✅ | 玩家有四个 Curios 槽位——背武器与腰带物品——会渲染在角色身上，并可用按键与主手互换。 |
| 好友与敌我识别 | ✅ | 每个玩家可以维护一份「视作自己人」的名单，按会话有效或随存档保存，其他模组或脚本也能通过 TriState 事件给出同样的答案；查询按**玩家 ID** 进行，因此装了 FTB Teams 时也能替离线玩家作答。 |
