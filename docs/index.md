# MiXianTu

MiXianTu（觅仙途，模组 ID `mxt`）是一个 NeoForge **修仙模组框架**。它提供修仙玩法所需的**通用规则与运行时**——修炼、灵气环境、境界与数值、技能、阵法、天劫、锻造、炼丹与经济——但不预设任何具体世界观数值。

具体物品、方块和配方由数据包、KubeJS 或其他内容模组提供，MiXianTu 的数据表与绑定表再赋予它们玩法。

- **玩家**：只装本体时得到的是框架物品、Curios 槽位、HUD 和命令；实际能玩到什么取决于你使用的数据包或内容包。
- **内容与模组作者**：用数据包、KubeJS 或 Java API 定义自己的修炼规则、灵气分布、技能、阵法、工艺和物品绑定，不需要改动模组本体。

::: warning 项目仍在开发中

项目尚未发布，数据包格式与其他接口都还不是最终形态，更新后可能不再兼容旧存档或旧数据包。会造成崩溃或数据丢失的改动会在更新日志里单独说明。

:::

## 模块完成度

- **✅ 完成**：已经实现，装上即可使用；后续仍可能有小幅调整。
- **🚧 制作中**：只完成了功能集的一部分，其余仍在开发。
- **🔲 预留**：只有数据结构或资源，或仅有开发计划。

| 模块      | 状态 | 说明                                                                                        |
|---------|:--:|-------------------------------------------------------------------------------------------|
| 数据包基本功能 | ✅  | 玩法规则由数据包描述：条件、效果、数值计算、物品匹配和触发时机都能自由组合，单个条目也可以随时停用。                                        |
| 轮盘与人物界面 | ✅  | 技能、灵气与法器技能共用轮盘：主盘 12 格自己摆，从盘（主手 / 副手 / 法器）随装备自动生成、满了自动开新页，按住 `R` 指向要用的那一格即可使用；另有资源条与人物信息面板。    |
| 资源系统    | ✅  | 可以定义修为、灵力等数值资源，按规则自动回复、被技能与修炼消耗，并显示为 HUD 上的资源条。                                           |
| 灵气系统    | ✅  | 世界按维度、群系和方块拥有不同浓度的灵气，并随时间与阵法变化；玩家能查询当前位置浓度，以粒子、雾效和 HUD 看到结果。                              |
| 修炼与境界   | ✅  | 玩家可以打坐修炼积累修为，灵气越浓效率越高；修为满足条件后可以突破到下一境界，突破条件由数据包规定。                                        |
| 元素      | ✅  | 定义元素以及元素之间的克制与适应关系，供灵根、灵气和其他玩法读取。                                                         |
| 灵根与体质   | ✅  | 灵根与体质可以授予给玩家，分别影响修炼与技能效果、或直接提供被动属性与伤害倍率，获取条件与互斥关系由数据包规定；已持有的灵根或体质也可以关闭而不失去。               |
| 功法      | 🚧 | 玩家可以学习功法获得主动招式或被动加成，并可用互斥标签限制不能同时修习哪些功法；功法可以绑定到任意已有物品作为载体。                                |
| 技能和诅咒   | ✅  | 技能可从轮盘施放，带有消耗、冷却、持续时间与目标选择，也能在攻击、受伤、击杀等时机自动触发；诅咒会附着在角色身上周期发作，并可通过净化解除。                   |
| 阵法      | ✅  | 玩家可以搭建并激活阵法，阵法持续消耗资源维持，在范围内执行效果并临时提供Buff/Debuff。                                          |
| 天劫      | ✅  | 境界突破时可以触发天劫：它按时间线逐拍消费（执行行为、空等一段时长，或等一个条件成立），难度随境界与当地灵气缩放，成败各自执行对应结果。                      |
| 生物档案和契约 | 🔲 | 生物档案为生物定义强度、内丹与掉落；玩家还能与生物签订契约，让灵兽跟随参战，并收进灵兽袋或用御兽铃召回。                                      |
| 秘境      | ✅  | 定义是模板：每次进入按需开出一份独立维度的实例，可声明边界、维度生成方式、结构与落点，支持认领、人数与实例上限、时限以及进出条件与行为。                      |
| 灵气工作台   | ✅  | 在灵气工作台上按灵气合成配方合成，除材料之外还要消耗灵气，取出成品时扣除。                                                     |
| 锻造系统    | ✅  | 在锻造台上用多种材料按蓝图锻打成品，不同工具解锁不同锻打方式，成品品质取决于锻打过程与步数。                                            |
| 炼丹系统    | 🚧 | 配方与结算逻辑已就绪（原料、灵气、温度、炉阶、成败产物），但**炼丹台本身还没开始做**，所以今天还没有开炉的入口；服用丹药有对应效果，过量会积累丹毒。              |
| 灵植      | 🔲 | 为灵植类物品定义绑定与品质，作为炼丹与采集玩法的材料。                                                               |
| 物品绑定    | 🚧 | 把已有物品接入玩法：给任意物品附加被动行为、武器伤害与攻速，或绑定右键使用与攻击时触发的技能。                                           |
| 符箓      | 🚧 | 用符笔把定义铭刻到载体上（一张可铭刻多条），按住右键灌满即发动铭刻的道法并消耗一张本体，并进入可配置的物品栏冷却。                                 |
| 物品品质    | 🚧 | 物品可以带有品质并显示在 Tooltip 中，可按品质分组与排序，品质分组也能作为条件被其他玩法读取。                                       |
| 法器      | 🚧 | 已有物品经 `artifact` 成为法器：按灵气收纳灵力，按列表授予主动/被动技能，可载人飞行、自带储物（飞行与储物都是轮盘上的一格）；精炼台仍未接入。                  |
| 经济系统    | ✅  | 把物品定义为货币并设置面值，支持兑换与找零；玩家之间可以直接交易，也可以使用交易站与支票完成交易结算。                                       |
| 饰品槽位    | ✅  | 玩家拥有背部武器、腰部物品与四个法器符位等饰品槽位，装备后显示在角色身上，并可用快捷键与主手交换。                                         |
| 好友与敌我识别 | ✅  | 每个玩家可维护一份"自己人"名单（临时或永久），其他模组或脚本可用 TriState 事件给出判断；判断按 **UUID** 提问，装了 FTB Teams 时对方离线也能作答。 |
