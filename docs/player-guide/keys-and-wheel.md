# 按键与轮盘

## 按键

| 按键 | 默认 | 作用 |
|---|---|---|
| 切换修炼模式 | `C` | 开始或停止修炼 |
| 打开 / 关闭人物信息面板 | `Z` | 打开人物信息面板 |
| 交换主手与背部武器槽位 | 未绑定 | 把主手物品与第一个 `back_weapon` 饰品槽互换 <br> 交换按键遵循的槽位规则见 [Curios 槽位](./curios-slots.md) |
| 编辑 HUD 布局 | 右 `Shift` | 打开可拖动 HUD 元素的布局编辑器 |
| 轮盘选择 | `R` | 打开技能与灵气选择轮盘 |
| 轮盘使用 | `V` | 使用当前选择的技能/灵气 |
| 轮盘向左 / 向右翻页 | `←` / `→` | 在轮盘界面使用，切换主盘/其他副盘 |
| 飞行下降 | `X` | 驾驶飞行法器时的下降键 |
| 打开轮盘配置 | 未绑定 | 打开轮盘配置界面（等同于 `/wheel`） |
| 轮盘槽位 1–12 | 未绑定 | 使用主盘对应编号技能/灵气，等同于把指针指过去再按 `V` |

## 轮盘

![主盘](/images/player-guide/main-wheel.webp)

轮盘用于选择技能与灵气。**主盘**是你自己摆的 12 格，**从盘**是装备给你的主动技能（主手、副手、法器声明的技能），主盘和从盘通过左右按键或者鼠标滚轮翻页切换。

**需要按键的技能。** 有一类技能**必须按键才发动**，它们和其它条目一样落在轮盘上：

- **施放**：已经学会的主动技（`mxt:active`）按一下施放一次。
- **定向施放**：定向技能（`mxt:targeted`）按一下也是一次完整施放，只是它先用选择器圈定**够得着的实体**（范围 / 射线 / 圆锥，**距离写在技能定义里**），再对每个目标跑它点名的那条载荷技能。
- **飞行开关**：学会**御器之术**（`mxt:flight_control`，通常由功法授予）之后，那一页就多出一格「御器之术」，**按 `V` 从主手、其次副手取一件会飞的法器起剑，再按一次落剑**。
- **储物**：法器声明了储物格数时，那一页会多出一格「储物」，**按 `V` 打开这件法器自己的箱子**。

## 轮盘配置

![轮盘配置](/images/player-guide/wheel-config.webp)

**主盘上放什么由玩家自己定。** 聊天栏打 `/wheel`，或按「打开轮盘配置」按键打开**轮盘配置界面**：

- 上一排是两个可选项池——**左边 6 列是能发射的灵气，右边 6 列是学到的技能（功法 / 灵根 / 体质 / 境界授予）与 Curios 槽位上法器声明的技能**（只由**主手 / 副手物品**声明的技能不在这个池子里）。
- 下一排是**共用的 12 格**，就是**主盘**的 12 格（**`1` 在正上方，顺时针**）。左键点池里一个条目选中它，再点某一格放进去；不选中条目直接点格子则清空该格。已填格子的底边颜色标明类型（灵气蓝、技能金；需要按键的技能按开 / 关取绿 / 灰、一次性取紫）。
- **只有主盘在这里编辑**：从盘的内容由随身装备。
- **新存档的轮盘是空的**：不会替你预填任何东西，得先在 `/wheel` 里把条目点进 12 格。**整张轮盘一格有内容的都没有**时按 `R` 不会打开轮盘（没东西可选），左边那块「轮盘格」这时是 4 个空框（一页三行）。
- 保存过的条目如果后来失效了（授予被撤销、定义被删、灵气不再满足条件），格子会显示一个红色的 `?`、tooltip 写明"已失效"，**它不会自己换成别的东西**——格子位置不会悄悄漂移，想清掉就点一下那个格子。

## 扩展/自定义

其他模组可以通过实现 `WheelMenuEntry` 接口来添加自己的技能或灵气到轮盘中。这个接口定义了条目的基本属性，包括类型、ID、标题、图标、提示信息、冷却时间、可用性以及选中时的回调函数。详见： [客户端轮盘](../java/wheel.md)。
