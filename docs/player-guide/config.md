# 服务端配置

本页收**服务端配置项**：它们按标签页分组，改完即时生效——服务端每次都读当前值，不缓存。它们**不是命令**，本页只写**服务端配置「标签页 → 条目」**，不写配置文件路径与键名。

## 符箓

画符工作站用的十项，加上管手持发动的使用冷却。判定用的时间一律是**服务端收到包时的游戏刻**，客户端报上来的时间与用量都不读。

| 条目 | 默认 | 管什么 |
| --- | --- | --- |
| 服务端配置「符箓 → 最小落笔间隔」 | `300`（毫秒） | 相邻两笔之间、以及"开画 → 第一笔"之间的最小间隔；`0` 关闭。低于它的那一笔**被拒收**。它拦得住"一瞬间灌进几百笔"，**拦不住按节奏自动描图的脚本**。 |
| 服务端配置「符箓 → 允许被拒的笔数」 | `3` | 一次绘制里被拒的笔数超过它，本次会话判失败（材料不退）。只有"过快"与"颜料不够"计入；"光标上已经没有那支笔了"不计。 |
| 服务端配置「符箓 → 单笔点数上限」 | `512` | 单笔的点数上限；超了这一笔被拒收。 |
| 服务端配置「符箓 → 单次绘制点数上限」 | `4096` | 一次绘制的累计点数上限；超了整次提交被拒收并记一条警告。 |
| 服务端配置「符箓 → 单次绘制笔画上限」 | `64` | 一次绘制的笔画数上限；同上。 |
| 服务端配置「符箓 → 符笔容量」 | `4000` | 一支符笔能装多少颜料，单位＝像素弧长。一张 90×210 的符，笔画总长通常在 400–1200，所以默认约能描满 3–5 张。 |
| 服务端配置「符箓 → 一份颜料的点数」 | `1000` | 一份颜料（`#mxt:brush_pigment` 标签里的一个物品，默认只有朱砂）蘸进符笔后给多少颜料。 |
| 服务端配置「符箓 → 颜料换算率」 | `1.0` | 每像素弧长扣多少颜料。 |
| 服务端配置「符箓 → 单笔颜料保底」 | `1` | 每一笔至少扣多少，免得"点一下"不花钱。 |
| 服务端配置「符箓 → 单笔颜料上限」 | `0` | 单笔最多扣多少；`0` 不封顶。 |
| 服务端配置「符箓 → 使用冷却」 | `20`（刻） | 徒手激发符箓后的物品栏冷却；`0` 不加冷却。冷却按物品算、对该玩家的所有符箓生效，冷却期间长按灌注也会被拒绝。 |

**判分参数不在配置里**：`pattern.tolerance` 与 `judgement` 跟着符方写在配方 JSON 里，见[画符判分](../technical/talisman-scoring)与 [talisman_drawing（画符配方）](../datapack/json/talisman_drawing)。

## 炼丹

| 条目 | 默认 | 管什么 |
| --- | --- | --- |
| 服务端配置「炼丹 → 每秒丹毒自然消退」 | `0` | 已有丹毒的活跃实体每秒消退多少，必须是有限非负数。默认不消退；设成正数后每累计 20 个实体活跃 tick 减一次。离线不减，也不给没服过丹的实体建立附件。 |

## 命令别名

服务端配置的「命令别名」标签页里，每一项就是一个顶层别名命令——条目名就是命令本身，默认全开。关掉只移除顶层写法，`/mxt` 下的入口始终完整。别名清单见[命令](./commands.md)。
