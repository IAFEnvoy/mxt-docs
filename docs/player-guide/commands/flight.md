# `/flight`

| 命令 | 作用 |
| --- | --- |
| `/flight fill`（= `/mxt flight fill`） | 把**当前玩家所骑飞行器**的空座位全部塞上僵尸（需要 gamemaster 权限）。僵尸**没有 AI、不会消失**，头上还戴着一顶**不毁的铁头盔**（原版口径：头上有东西就不被日光点燃，所以白天也不会烧掉），位置由载具自己按定义里的 `seat_offsets` 摆放，所以它是拿来**对着实机调座位落点**的参照：改完定义 `/reload` 一下，它们当场跟着换位。它们随这一趟飞行结束（落剑、下线、撞地……）一起消失。没在御剑飞行、或座位已经坐满时会说明原因。 |
