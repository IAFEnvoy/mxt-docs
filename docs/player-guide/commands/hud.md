# `/hud`

不带参数时列出框架登记的全部可移动 HUD 元素：布局键、显示名、**绑定的锚点**、位置、尺寸、当前要画几个块、是否可见、是否可拖。

<div class="cmd-tree">

- `/hud ...`

  - `... open`

    打开 HUD 布局编辑器，等同于按键 `key.mxt.hud_layout`（默认右 `Shift`）。

  - `... <布局键> reset`

    把某个元素复位到它自己的默认位置，布局键见 `/hud` 的输出（如 `resource_bars.left`）。

</div>

复位会**同时删掉这个元素已保存的那一项**，所以它跨重启有效；删掉之后这个元素重新跟着窗口走（默认位置就定义在窗口上），直到你再次拖动它。

`/hud` 是**客户端命令**：它注册在客户端自己的命令表里，不进 `/mxt` 树、也不发往服务端，所以只在聊天栏里手打有效（写进命令方块、或由别的模组代为发送都不行），不需要任何权限。这条命令与按键 `key.mxt.hud_layout` 打开的是同一个编辑器。
