# `/physique`

体质的管理入口。定义本身是数据包，授予、移除和开关则是实体身上的状态：这一页是操作这三件事的地方，也是「关闭但不失去」那个模块在体质一侧的管理员侧入口（模块没有玩家界面）。

<div class="cmd-tree">

- `/physique ...`

  - `... list [<target>]`

    列出持有的体质：名字、品质与是否生效（叠加时同名只列一行）；不填目标时看自己，查询不需要权限。

  - `... grant <targets> <physique>`

    授予体质（gamemaster）。

  - `... remove <targets> <physique>`

    移除该体质，连同它给的属性与一切授予。

  - `... enable <targets> <physique>` / `... disable <targets> <physique>`

    与灵根同义的开关：关闭后属性修正、授予能力与两个伤害倍率全部不生效，但体质仍然被持有。

</div>

「品质」那一栏读的是定义自己声明的 `quality`；定义没声明、或者那份定义当前包已经不提供时，这一栏写 `-`。信息面板里体质那一行画的是「定义名 · 品质名」，没声明品质时那半段整个不画。

授予与移除走的是数据包行为 `mxt:grant_physique` / `mxt:remove_physique` 等**同一套服务**，所以持有条件、互斥标签与来源清理完全一致，命令不会绕过任何一条校验。失败按目标逐个报告，原因写在后面。
