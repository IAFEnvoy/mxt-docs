# `/display`

在聊天里展示一件装备物品，也可以只展示给某一名玩家。每个节点也可以写成 `/mxt display …`，且只能由玩家执行。

<div class="cmd-tree">

- `/display`

  展示自己的主手物品，广播给全服。

- `/display <player|slot>`

  填槽位名就展示自己那个槽位并广播；填玩家名就只把主手私聊给那名玩家。

- `/display <player> <slot>`

  把指定槽位私聊给那名玩家。

</div>

槽位名是 `mainhand`、`offhand`、`head`、`chest`、`legs`、`feet`；物品为空、玩家名对不上或槽位名不认识时都会说明原因。展示出来的物品带原版的物品悬停信息。
