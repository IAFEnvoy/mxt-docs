# `/trade`

| 命令 | 作用 |
| --- | --- |
| `/trade <player>`（= `/mxt trade <player>`） | 向玩家发起交易请求。 |

对方接受后双方各开一个交易界面：各自往自己的报价格里放东西，按「确认」表示同意这一次的报价。

**确认绑定的是报价当时的样子。** 任何一侧在确认之后改动自己的报价（拿走、放入、shift 点击、数量变化），双方的确认都会作废，要重新按；只有两边都对着同一份报价按过确认，交易才会成交——所以不存在"趁对方按了确认再换东西"。

**关掉界面就是结束这场交易**：无论是按 Esc、被别的界面顶掉，还是服务端关闭，报价格里的东西都会原样退回各自身上，双方也都不会再卡在"交易中"。
