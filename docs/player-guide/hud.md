# HUD 与面板

可拖动的 HUD 元素、资源条与灵气浓度条的画法，以及 `Z` 打开的人物信息面板。按键本身见[按键与轮盘](./keys-and-wheel.md)。

## HUD 布局编辑器

按「编辑 HUD 布局」（默认右 `Shift`）打开一个独立的布局界面：框架登记的每个可移动 HUD 元素都会画出半透明矩形与名字，**左键拖动**，或用**方向键**一次挪 1 像素（按住 `Shift` 为 10 像素），`Esc` 放弃当前选中的元素；右下角的完成按钮关掉界面。位置会立刻写进 HUD 布局文件，所以拖到一半退出也不会丢。这一版的编辑器多了三件事：**窗口边上那八个方框是锚点**——把元素拖到某个方框上就自动绑定到它（绑定不会让元素跳一下，只改变"位置从哪个点量起"，之后窗口变大变小它就跟着那个点走），并画一条从锚点到元素的连接线；**元素右上角框内的小方框是显隐勾选框**，取消勾选后这个元素不再画出来，但在编辑器里仍然是半透明的一块（勾选框本身不透明），随时可以勾回来；**选中在松开鼠标后保留**，所以方向键微调与那条连接线不用一直按着鼠标。

**现在可以拖的是资源条的左右两列与轮盘的「轮盘格」那一块**——屏幕中心两侧那两条竖排的条，每列是一个整体；轮盘格默认贴在屏幕左边、竖直居中，冷却直接画在格子上（一层随时间往下退的白幕）。资源本身显示在左列还是右列由数据包声明（`resource.bars` 的 `anchor`），但**列摆在哪里是玩家自己的设置**：把两列拖开可以避开别的模组的 HUD，或者把右列挪到中间看目标身上的资源。目标与 Boss 的覆盖条钉在准心所指的实体上，不参与拖动。编辑器里背景**不做模糊**（否则要摆的元素自己也糊了）。

元素的位置按**窗口锚点 + 像素偏移**保存（`config/mxt/mxt-hud.json` 的 `layout` 表，键是 `resource_bars.left` / `resource_bars.right` / `wheel.selection`，值形如 `{"anchor": {"horizontal": "center", "vertical": "bottom"}, "offset_x": -55, "offset_y": -47, "visible": true}`），换分辨率或改 GUI 缩放后布局不会跑偏；元素始终被夹在窗口内，缩窗口时贴边但不改写存档，窗口还原后回到原处。这个文件由模组自己读写（不再挂在设置界面的配置框架下）。

没拖过的列按默认位置摆放：**默认锚点是窗口的「下边中点」**，左列中点在中线左侧、右列在中线右侧（离中线 `20 + 半列宽` 像素），锚点高度是屏幕底部向上 47 像素——也就是原来那两列所在的位置。列里的条变多变少时从下边缘往上长，下边缘不动；窗口变化时默认位置跟着走。把列拖到别的锚点方框上（左中、右上、下中……）就换成那个锚点，之后它跟着那个点走。**没有资源条的存档里，两列仍然会画出空框**，这样你能先摆好位置，等有内容时直接用。

::: info

布局编辑器是给模组自己画 HUD 元素的框架用的，目前接进来的是资源条两列与轮盘格。查不到东西时可以在聊天栏打 `/hud`：它会列出每个可拖动元素的布局键、**绑定的锚点**、位置、尺寸和当前有没有内容；`/hud <布局键> reset` 把某个元素放回默认位置，并**删掉已保存的那一项**（所以重启后它仍在默认位置）。框架的扩展方式见 [客户端界面](../java/screens.md)。

:::

## 资源条与灵气 HUD

资源条和灵气浓度条由服务端同步状态驱动，客户端只负责绘制。服务端按服务端配置里的「灵气 → 同步周期」（默认每 5 tick）同步当前位置灵气，雾效和粒子不会反向决定灵气数值。

| 客户端设置 | 作用 |
|---|---|
| 客户端设置 → 资源条 → 显示名称 | 在每条资源条旁显示资源名。 |
| 客户端设置 → 资源条 → 图标布局 | 图标画在资源条「两侧」（默认）还是「中间」。 |

## 人物信息面板

没有其他界面打开时，`Z` 打开**人物信息**面板（`screen.mxt.information_panel`）；面板开着时再按一次 `Z` 就关掉它（`Esc` 同样能关）。面板左上角两个页签（**人物信息**与**习得功法**）在两页之间切换，两页共用同一块面板，面板上不再另有一行标题。

| 分组 | 内容 |
|---|---|
| 基础信息 | 生命、饱食度、经验等级、所在维度。 |
| 修炼信息 | 境界（未入道时为「凡人」）、修炼进度、此刻是否在修炼、突破状态、灵根、体质与已学功法。 |

突破那一行会说明所需进度够不够、条件满没满足。客户端设置 **客户端设置 → 信息面板 → 刷新间隔**（默认 20）决定面板多久刷新一次。

## 习得功法页

**习得功法**页（`screen.mxt.technique_panel`）是人物信息面板的第二页，用左上角的**习得功法**页签切换。它按行列出你学过的每一门功法，比一页长时可以滚动；按 `Z` 打开人物信息面板，再点左上角的「习得功法」页签即可。

| 行内元素 | 内容 |
|---|---|
| 图标 | 功法自己的图标，画在一个格框里；功法没有定义 `icon` 时格框留空。 |
| 名称 | 功法自己的名字，用普通文字颜色绘制（**功法不再有自己的品阶**，所以没有按档位上色这一说）。一行放不下的名字用省略号截断，旁边的等级不会被名字挤掉。 |
| 等级 | 你所在的那一级的名字，加上你在整条链上的位置，写成 `等级 <名字>（<第几级>/<总级数>）`。数据包没给这一级写名字时退回级数。 |
| 熟练度 | 相对下一级所需量的熟练度，写成 `<当前> / <需要>`；已经在链顶端时写「已圆满」。 |
