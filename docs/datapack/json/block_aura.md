# block_aura（方块灵气） {#block_aura}

文件位置：`data/<namespace>/mxt/block_aura/<path>.json`

**用途**：方块提供的灵气。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `blocks` | `HolderOrTag<Block>[]` | **必填** | 匹配的方块或方块标签。 |
| `aura` | `Map<Holder<aura>, AuraValue>` | `{}` | 每个方块提供的灵气数量、容量、恢复速度和颜色。 |

区块加载、方块变化或数据表加载后重建缓存。灵石矿脉可以通过多个 `block_aura` 条目和方块标签提供高于自然环境的灵气。运行时按 7×7×7 子区块范围查询：当前子区块周围 3×3×3 范围使用匹配方块的真实位置，外围使用子区块中心近似，统一按 `1 / max(1, 距离平方)` 衰减；每个来源子区块的贡献会根据当前访问玩家数粗略平分，库存仍是区块范围共享的。
