# alchemy_furnace（炉型） {#alchemy_furnace}

一份 `alchemy_furnace` 是**炉型规格**，不是世界里的那一块方块。它说这座炉子能用几个主药格和辅药格、一炉最多放几件材料、炉温过高或停止供热后每 tick 回落多少，以及炉型自己的默认品阶。

丹炉核心用组件 `mxt:alchemy_furnace` 携带一份规格。没有这个组件、或它指向的定义不在注册表中时不能开炉，也不会悄悄换成一个内置炉型；放置、存档和正常拆回都保留这份组件。

## 文件位置

炉型文件放在数据包的 `data/<namespace>/mxt/alchemy_furnace/`。

**用途**：炉型规格。

文件名对应它的 ID。例如 `data/example/mxt/alchemy_furnace/clay_kiln.json` 的 ID 是 `example:clay_kiln`。

## 字段

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `name` | Text Component | `alchemy_furnace.mxt.<命名空间>.<路径>` | 炉型显示名。 |
| `description` | Text Component | 同上加 `.description` | 炉型描述。 |
| `main_slots` | Integer | **必填** | 主药格数，`1..2`。 |
| `auxiliary_slots` | Integer | `0` | 辅药格数，`0..2`。 |
| `quality` | 品阶 id | **必填** | 炉型默认品质。只用于展示与使用条件，不推导槽位、容量、回落或耐温。 |
| `capacity` | Integer | **必填** | 一炉材料件数上限，`1..320`；还要服从物品自己的堆叠上限。 |
| `cooling_per_tick` | Double | **必填** | 炉温高于设定值或没有供热方块时每 tick 回落的量，有限正数，不越过设定值：供热格里有热源时炉温被推向设定值，那一格空着或放的是没有热量的方块时一路降到 `0`。 |

药引固定在辅药仓的第三格，不用字段声明。物理库存是固定的：主药仓 2 格、辅药仓 3 格（2 格辅药加 1 格药引）、产物仓 4 格；规格没用到的主药或辅药格不能放入。开炉扣的是两侧投料仓**已用格子的全部数量**，不是每格只扣一件。

```json
{
  "main_slots": 2,
  "auxiliary_slots": 2,
  "quality": "example:common",
  "capacity": 64,
  "cooling_per_tick": 0.5
}
```

炉型的 `quality` 只落在展示与使用条件上：炉体自己的炼丹修正不缩短时长，光改物品上的品质组件也不改变规格里的任何参数。

## 丹炉的结构

丹炉不是单方块：玩家手搭一个固定的 3×3×3，没有数据包结构 schema，形状也不能自定义。

| 位置 | 方块 | 作用 |
| --- | --- | --- |
| 正面这一层的中格 | 丹炉核心 | 记这一炉并携带炉型规格；炉温读数与「设定 / 开炉 / 终止」在它的页面上。 |
| 核心后方的左格 | 主药投料仓 | 两个主药格。 |
| 核心后方的右格 | 辅药投料仓 | 两个辅药格加一个药引格。 |
| 中层中心格的**上方**（顶层正中） | 丹炉产物仓 | 四个产物格，只能取出。 |
| 其余 18 格 | 丹炉炉壁 | 每块携带一种炉壁材料，不打开界面。 |

朝向默认朝北，水平旋转时整座壳一起转，需要校验的格子一共 22 个（底层四角加上面两层）。**底层只有四角算结构**，其余五格完全不校验：放什么、放不放、区块有没有加载都不影响成型，也不会被认领；整块底面由四角的模型各画四分之一拼出来，所以那五格空着也照样完整。其中**底层正中央那一格是供热格**，放什么由玩家决定，有热源方块才供热，见 [heat_source](./heat_source.md)。壳不齐、炉壁材料缺失或无效、格子被别的炉占了，都不能成型，也不能开炉；界面用文字列出缺了什么。

## 炉温上限

可设的炉温上限是**两者中较低的那个**：18 块炉壁里最低的耐温，与供热方块的 `max_temperature`。设定温度必须有限、落在 `0` 到上限之间，运行中可以改，非法请求会被拒绝；第一次开炉时它还必须落在配方的温区容差内。

供热方块放在**底层正中央那一格**（本地 index 4，上层炉体中心的正下方），读的是 [`mxt:heat_source`](./heat_source.md) 表；方块自己实现 `AlchemyHeatSource` 时以它自己的回答为准。本体没有默认热源方块，也不内置岩浆、火这类数值。炉型规格里没有耐温字段：一座炉子能烧到多热，取决于砌了哪些[炉壁材料](./alchemy_wall_material.md)和那一格里放了什么供热方块。
